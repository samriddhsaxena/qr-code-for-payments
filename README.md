# 💰 Payment QR Code Generator (Python)

A simple **Payment / Money Transaction QR Code Generator** built using Python's [`qrcode`](https://pypi.org/project/qrcode/) and [`Pillow`](https://pypi.org/project/Pillow/) libraries.  
Easily generate scannable QR codes for payment links — such as **UPI**.

---

## 🚀 Features
- Generate QR codes for payment URLs (e.g., UPI, PayPal, Razorpay, etc.)
- Save the generated QR code as an image (`.png`)
- Lightweight and beginner-friendly Python project

---

## 🧾 Example Use Case
- Create UPI payment QR codes for quick transactions.  
- Generate QR codes for digital wallets or e-commerce payments.  
- Share your payment QR code for donations or freelance work.
